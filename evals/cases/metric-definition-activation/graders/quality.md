Judge the final response, a single-role product-manager critique. It PASSES only if all four hold.

1. Sources: the main findings cite a named author and work or a named framework (for example Cagan, Torres, Dunford, Moore, Kohavi, Goodhart), and no citation is fabricated or decorative. FAIL if most findings are uncited "best practice" claims.
2. Distinct findings: at least three findings that are different from one another, not one point restated. FAIL if the response is a paraphrase of the input or repeats a single issue.
3. Trade-off: at least one explicit trade-off or conflict is named (for example scope versus schema impact, speed versus a safe rollout, specificity versus reach) with a stated position. FAIL if every finding is presented as free of cost.
4. Actionable: the response ends with one to three concrete next actions, each with a deliverable, so a reader could start work without asking a follow-up. FAIL on "iterate", "align" or "more research".
