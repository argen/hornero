## Reading order for a new agent

If you're an agent about to adopt the designer role on a non-trivial task and you've never read these, here's the priority order:

1. **[`norman-design-of-everyday-things.md`](norman-design-of-everyday-things.md)** — the foundational vocabulary (affordances, signifiers, mappings, feedback, constraints) that every modern UX heuristic descends from.
2. **[`nielsen-ten-heuristics.md`](nielsen-ten-heuristics.md)** — the canonical heuristic set, severity-rating scale, and discount-usability rationale; powers `heuristic-review`.
3. **Krug — Don't Make Me Think** (note pending) — recognition-over-recall in working-designer voice; the day-to-day usability test mindset.
4. **Holmes — Mismatch** (note pending) — inclusion-not-compliance framing; powers `accessibility-audit`.
5. **Tufte — Visual Display of Quantitative Information** (note pending) — data-ink discipline; powers dashboard/data-viz critique.
